DEFINICIÓN

- El usuario puede acceder una vez su plan se ha generado
- El usuario puede ver un catálogo de mentores en format o cards
- El usuario puede ver la valoración del mentor desde la card, sin entrar al detalle
- El usuario puede ver tags que clasifican a cada mentor
- El usuario puede ver imágenes de los mentores
- El usuario puede ver los días de salidas semanales de cada mentor
- El usuario debe elegir un mentor obligatoriamente para continuar
- El usuario puede cambiar de mentor si no está alineado con él
