
DEFINICIÓN

- El usuario puede registrarse con email (Gmail, Outlook u otros)
- El usuario puede escanear el código de barras con la cámara
- El usuario puede introducir el código manualmente
- El usuario debe dar permiso al smartphone para usar la cámara
- Si el código ya está en uso, aparece un pop-up de error
- Si el código es válido, aparece un mensaje de éxito
