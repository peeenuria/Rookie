DEFINICIÓN

- El usuario puede ver el calendario del mentor
- El usuario puede ver los slots disponibles para elegir fecha de sesión
- El usuario puede ver las salidas grupales disponibles
- El usuario puede apuntarse o no a una salida grupal
- El usuario puede cancelar una cita ya confirmada
- El usuario recibe la información de la sesión (enlace Google Meet, hora, fecha)
- El usuario ve una confirmación de cita al finalizar
